# Wordgrove｜單字記憶花園

使用繁體中文介面的英文單字間隔複習工具。從 `dist/index.html` 開始，或以靜態伺服器提供 `dist` 資料夾。

## 使用方式

1. 在「學習總覽」按開始學習，每次最多認識 10 個新單字。
2. 先回想中文意思，再顯示答案，依實際熟悉程度評分。
3. 「今日複習」優先安排已到期的單字；沒有到期項目時，安排新單字。
4. 在「我的單字庫」新增單字、搜尋、篩選及匯入／匯出備份。
5. 在「學習足跡」查看最近 7 天回想次數與未來到期單字。

## 複習規則

這是依自行評分調整的間隔複習安排，並非個人記憶能力的科學測量。

- 忘記了：回到起點，10 分鐘後複習。
- 有點模糊：回到短期練習，30 分鐘或 1 天後複習。
- 記得：延長一階，間隔為 1、3、7、21、60 天。
- 很熟悉：延長兩階，最長 60 天。
- 目前排程間隔達 21 天以上即標記「已熟記」；之後忘記或模糊會降級。

統計僅代表這個單字庫的學習情況，不能推估使用者整體英文詞彙量。

## 保存與備份

單字、排程和紀錄使用瀏覽器 localStorage 保存。同一瀏覽器及同一網址下會保留進度；跨裝置不會自動同步。清除網站資料或使用無痕模式可能失去進度，請定期匯出 JSON 備份。匯入備份會取代現有進度，操作前會顯示確認。

英文發音使用瀏覽器提供的 Speech Synthesis API，可用性依裝置與語音服務而異。字型從 Google Fonts 載入，無法連線時會使用系統字型。網站的主要操作不需外部資料 API。
