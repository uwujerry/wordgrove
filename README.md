# wordlilium｜小百合記憶花園 v2

網站上傳入口：工作資料夾根目錄（與 `outputs` 同層）的 `index.html`，或來源壓縮檔根目錄的 `index.html`。此入口以相對路徑載入 `outputs/wordgrove/` 中的程式與樣式；上傳時請保留這個資料夾結構。來源壓縮檔已包含對應結構。原本的 `Wordgrove.html` 保留供既有使用者開啟。

繁體中文介面的英文單字學習工具；英文使用 Times New Roman，中文使用使用者提供的 GENJYUUGOTHIC-BOLD.TTF。

## 開啟

直接用瀏覽器開啟同一輸出資料夾中的 `Wordgrove.html`（字庫、程式及字型均已內嵌），或開啟本專案 `index.html`。程式、樣式與字型位於專案根目錄，來源說明位於 `dist/data`，主要功能不需要外部資料 API。

VS Code 專案來源：

- `index.html`：頁面與對話框。
- `style.css`、`features.css`：字型、版面與功能樣式。
- `app.js`：六個頁面與互動流程。
- `model.js`：進度資料、排程、填空與備份合併規則。
- `catalog.js`、`dist/data/wordgrove-catalog.json`：內建字庫。
- `tools/package.py`：以 Python 標準庫產生單檔 HTML 與來源 ZIP。

## 兩個分類，避免重複

官方 6000 字共 6,008 詞條；學測常考字 160 詞條是其中一個標籤分類。同一單字不重複建立，兩類共用學習成果。另可新增個人單字。

本版收錄 13,913 個核心／常用義項與 27,828 個英文例句；每個收錄義項至少兩個不同的例句。這是學習義項選集，不是所有古語、方言與專業義的完整辭典。來源、改作方式與授權見 `dist/data/CONTENT-SOURCES.md`，也可從網頁的「查看來源與授權」閱讀。

## 回想複習

從「今日複習」選擇分類，再選到期義項或新義項。每個意思分別記錄，不會因記住一個意思就把其他意思算成熟記。每次新字上限可設 1–50，預設 10 個單字；每個單字可能需要練習多個意思。

忘記：10 分鐘；模糊：30 分鐘或 1 天。記得依序延長至 1、3、7、21、60 天；很熟悉可多前進一階。單字的所有收錄義項皆達到 21 天間隔才標示已熟記。

## 例句填空

選擇字庫與「全部／已學習／到期」範圍，每次隨機最多 10 題。填入英文，忽略大小寫、頭尾空白及全形英文字的差異；必須使用符合原句的單複數、時態等字形。答案以原例句中實際挖空的字形為準，不是任意近義字。

一題第一次作答記錄一次。答對記為「記得」，使用首字母提示後答對記為「有點模糊」，答錯或選「我忘記了」安排 10 分鐘後複習。重複按檢查不會重複增加紀錄。

## 每日單字本

完成回想評分或填空後自動記錄當地日期。第一次練習的詞條列入當日「新認識」，後續日期再次出現列入該日「再次複習」。同一天練習多個義項不會重複計算單字數。可按日期查看、重練新字、練習整本例句填空，或匯出單字表。

## 自訂內容

從單字詳情編輯不同意思；每個意思需至少兩組不同的中英文例句。既有義項的 ID 與進度會保留。隱藏單字不刪除進度，可在字庫還原。

## 舊版資料與備份

舊版 `wordgrove.v1` 資料保持原樣；新版首次開啟時會讀取並合併，保存到 `wordgrove.v2`。舊單字已有的進度只移到第一個義項，其餘意思不會被誤認成已學會。舊例句保留在個人筆記；不在官方字表的個人單字會保留。

「合併學習備份」接受新版進度、原先的舊版備份及已產生的 160 字匯入檔，保留現有紀錄並避免重複匯入。合併不會清空進度。原始官方字庫 JSON 不等於學習備份，不需手動匯入（現在已內建）。

進度使用目前瀏覽器的 localStorage，不跨裝置自動同步；更換網址、檔案位置、瀏覽器或清除網站資料可能影響可讀到的進度，請定期匯出備份。瀏覽器語音能否播放取決於裝置。

## 檢查狀態

填空以原句用字為回想目標，不是所有英文改寫的文法評分器。第一次非空白錯誤先顯示紅色提示，區分同詞族、收錄的字形變化、近義用法或拼字問題；不顯示原句答案。修改後可再答一次，第二次提交或「我忘記了」才揭曉。第二次答對或曾查看提示者排程為 hard；答錯為 again。每題完成時只記一筆紀錄，二次作答題仍可進入加強回合。

已檢查完整字庫結構、兩例句覆蓋、所有詞條都有填空題、字義獨立排程、日期單字本、舊版遷移、重複合併及互動頁面生命週期。瀏覽器工具禁止讀取本機 file:// 協定，因此本次未完成實際瀏覽器操作與視覺排版驗證。

首頁「學習備份」可匯出 JSON 紀錄，並在另一個瀏覽器匯入。包含各義項進度、作答紀錄（每日單字本）、個人單字與修改、隱藏單字及新字數設定；匯入合併現有進度並去除重複紀錄。儲存失敗時保留原狀。

填空回合結束後可「再練錯題」，只練剛才答錯或忘記的例句。作答後區分已收錄的動詞變化與接近的拼字（字母順序、增減或替換一個字母）；提示不會把錯字算成答對。答案區可播放完整例句，語音取決於瀏覽器支援。

同義字清單：學習中可點「同義字／易混淆字清單」開啟表格，不在題目下自動展開。採 Open English WordNet 2025（CC BY 4.0），逐一查詢所有 6,008 詞條：5,394 詞有同義群組、548 詞在來源中沒有其他可列出的同義詞、66 詞未收錄；共 19,481 群組、47,719 配對紀錄。按本題詞性分列各個意思，以英文釋義為準；中文不再直接採用單字的第一個意思，而是對應英文同義群組的釋義；缺漏部分已附自動翻譯，仍保留英文供核對。近義字不保證可直接代換句子。答題中開表計為提示，隱去目標詞；易混淆字另列。資料索引為 relations.js，覆蓋報告與授權位於 dist/data/synonym-coverage.json、SYNONYM-SOURCES.md、OEWN-LICENSE.md。

深夜模式：右下角使用使用者提供的圖片作為圓形按鈕，點擊切換日間／深夜模式。偏好儲存在瀏覽器，並包含於學習備份設定中。圖片檔為 `night-mode-icon.png`，單檔版本內嵌圖片。

首頁：滿版天空插畫與透明頂部導覽，向下可見常用功能、學習數據、字庫及備份。快捷入口依最近 14 天的功能頁面切換次數排序，同次數以最近使用者優先；預設為複習、填空、字庫、單字本。記錄最多 200 次，僅存於目前瀏覽器，不計為學習作答。首頁天空為本專案 SVG 插畫 `home-sky.svg`，不是參考截圖。左上品牌僅保留英文 wordlilium。

學測高頻字：根據 111–115 學年度正式試卷的實際字形與字庫收錄變化，至少兩年出現、共至少三次，排除部分功能字後共 710 詞；包含題幹、選項及文章，不是答案出現次數或必考承諾。此分類共用原單字進度，依出現年度數、優先第 3–6 級、次數排序；預設學習分類改為高頻。原 160 字常考分類保留。詳細次數見 dist/data/GSAT-HIGH-FREQUENCY.json。

同義字例句：清單每一筆均附至少一個本義例句，易混淆字也附例句。例句取自同一 OEWN 義項、嚴格篩選的 Open Dictionary 詞義內容、將來源名詞片語補成完整句子的改寫，或針對實際義項補寫。尚無合適例句的原始配對保留於資料索引，但暫不在表格顯示；英文釋義始終為準，不宣稱所有自動配對皆經人工審核。breed 的 spawn、engender、cover、multiply 已針對畫面中的義項補寫中英文例句並修正中文。重建資料時先執行 tools/build_synonyms.py，再執行 tools/enrich_synonym_examples.py；需要 work 中的原始開放字典及 WordNet 資料。

全部內建單字的中文釋義與 27,828 例句的繁體中文翻譯已補齊；同義字表顯示的 9,982 筆例句也附中文，英文同義群組的釋義另附中文譯文。保留既有翻譯，缺漏使用本機翻譯模型與 OpenCC，並對抽查中的錯誤補正；自動翻譯不代表所有句子已經人工校對。zhSource 記錄來源，介面懸停翻譯可見提示。模型只在建置時使用，網頁不下載模型或呼叫翻譯服務。

自訂單字編輯器已新增兩個中文例句欄位，儲存時要求中英文齊全；舊備份仍可匯入。舊編輯中未改動英文、但未填中文的例句，會優先使用同一義項的內建翻譯，保留使用者已有的翻譯。全新自訂句子需由使用者在編輯器提供中文，既有個人句子不會送往外部服務。單字本 TXT 匯出包含中英文。

重建補譯順序：build_synonyms.py → enrich_synonym_examples.py → fill_chinese.py → repair_chinese.py → package.py。翻譯建置需 work 中的模型與套件；網站本身僅使用已產生的靜態資料。翻譯來源與方法見 dist/data/CHINESE-TRANSLATION.md。


## 今日複習與到期通知

- 今日複習依到期義項出題，每個義項隨機取一個可填空例句，保留到期先後順序，不限於十題。
- 作答採兩階段字母提示與第二次機會，答完才可開啟同義字及單字庫例句。每個義項完成後更新一次原記憶排程。
- 今日複習不插入額外填空複習，以免同一時段重複升級記憶間隔；原本「例句填空」的五題與整回合複習仍保留。
- 網站開啟時每 30 秒檢查到期項目，顯示站內提醒；回到頁面時也會檢查。背景分頁的檢查可能受瀏覽器節流影響。
- 可在今日複習頁點「開啟到期通知」授權系統通知。HTTPS 與支援通知的瀏覽器才可啟用；檔案版仍有站內提醒。
- reminder-worker.js 供支援的瀏覽器顯示通知及處理點擊；不快取網站、不持續執行計時器、不提供伺服器推播。
- 網站關閉後無法自動排程通知；iPhone 等裝置的系統通知仍受平台及安裝條件限制。
- 通知按每個義項的到期時間去重，隱藏的單字不通知。通知內容不包含個人填答。


## 私人筆記

- 右上方「我的筆記」支援新增、編輯、搜尋、刪除與關聯單字；單字詳情及填空答完後可按「寫筆記」。修改後按儲存。
- 筆記存在原本的瀏覽器學習資料中，會隨 JSON 備份匯出、匯入；舊版沒有筆記的備份仍可匯入。
- 合併筆記時依更新時間取較新版本；刪除也保留記號，避免匯入舊備份時重新出現已刪除的筆記。

## 答案差異回饋

例句填空、五題／整回合複習與今日複習共用差異回饋。第一次答錯只提示詞性、意思方向、時態或搭配，不揭曉原句用字，保留一次修改機會。完成後並列輸入與答案的中文意思、詞性，常見易混淆組另補用法比較及可展開的中英示例；第二次答對仍回顧第一次輸入。未知字只提示無可靠釋義，不臆測意思。

比較依本機字庫及人工整理規則產生，不會傳送使用者答案到外部服務。近義替換可能成立，畫面會提醒評分核對的是原句用字，並不宣稱能判斷所有英文改寫的文法。規則測試涵蓋 safe/safety、economic/economical、borrow/lend、動詞變化、近義字、未知輸入、答案隱藏及輸入跳脫；實際瀏覽器視覺效果尚未驗證。
